# 羅賓漢射氣球 Robin Hood Balloons

https://gabrielsun77.github.io/robin-hood-balloons/

橫向手機射箭小遊戲，純 HTML + Canvas，單一檔案、無任何相依套件。

## 玩法

- 按住右下角的按鈕拉弓，放開射箭。按得越久箭越快，共 5 階；第 3 階起箭矢分別纏繞綠色的風、藍色的雷、黃色的光。
- 羅賓漢固定站在左側，箭沿水平線筆直飛出（忽略重力）。
- 氣球分紅、藍、綠、黃四色，飄速與分數依序遞增（紅 10、藍 20、綠 30、黃 50）。紅色會整排一起升起；氣球飄出頂端後從底部循環。
- 一箭可連續穿破多顆氣球，第 n 顆額外獲得 20 × (n − 1) 分的連穿獎勵。
- 每關氣球射完後，十環標靶會從最右側升起、碰頂反彈上下循環；命中後依環數給予環數 × 50 的獎勵分並進入下一關。
- 初始 20 支箭，每過一關補 20 支；箭用完時每 100 分可自動換 1 支。沒箭、分數不足 100，且場上仍有氣球或標靶時遊戲結束。
- 共 10 關，第 1 關 10 顆氣球，之後每關 +5 顆。全部通關後依分數與通關時間登錄最佳紀錄（同分以用時較短者為準），紀錄存在瀏覽器的 localStorage。

## 執行

直接用瀏覽器開啟 `index.html` 即可。手機請橫向遊玩。

若要放到 GitHub Pages：把本資料夾內容推到 repo，於 Settings → Pages 選擇分支與根目錄，稍待幾分鐘即可透過 `https://<帳號>.github.io/<repo>/` 遊玩。

桌機測試時可用空白鍵代替按鈕（按住蓄力、放開射箭）。

## 檔案

- `index.html` — 遊戲本體（含全部 CSS 與 JavaScript）。
- 字型 Cinzel 與 Noto Sans TC 由 Google Fonts 載入；離線時會自動退回系統字型，不影響遊玩。
